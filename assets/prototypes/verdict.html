Arkusz Werdyktu 🪵

  1. Cel ma Herezję ≥ progu (domyślnie 7).
  2. Oskarżyciel ogłasza cel (1× przeciw temu graczowi / Erę).
  3. Głosowanie jawne: każdy poza oskarżonym — Skazać / Uniewinnić.
  4. Remis → Uniewinnienie.
  5. Skazanie: Agent → Stos lub Lochy +1 Herezja.
  6. Uniewinnienie: oskarżyciel +1 Herezja.
