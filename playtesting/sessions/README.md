# Sesje playtestowe

Notatki z rozgrywek papierowego prototypu. **Nie commituj fikcyjnych wyników** — tylko realne sesje.

## Naming

```
YYYY-MM-DD-skrot.md
```

Przykład: `2026-08-15-3p-oficjum.md`

1. Skopiuj [`_TEMPLATE.md`](_TEMPLATE.md)
2. Uzupełnij po sesji
3. Soft-spoty / decyzje → [`../balance-notes.md`](../balance-notes.md) (nadpisz stan, nie dokładaj historii)

## Checklista przed sesją

- [ ] Setup **3 / 4 / 5p** z [`../setups.md`](../setups.md)
- [ ] Warstwa **C** (pełne mechaniki — domyślna sesja)
- [ ] Próg oskarżenia (**6** w 3p, **7** w 4–5p)
- [ ] PnP: [`../../assets/prototypes/`](../../assets/prototypes/)
- [ ] Teach: [`../../docs/rules/teach-sheet.md`](../../docs/rules/teach-sheet.md) · księga: [`../../docs/rules/ksiega.md`](../../docs/rules/ksiega.md) · słownik: [`../../docs/rules/slownik.md`](../../docs/rules/slownik.md)
