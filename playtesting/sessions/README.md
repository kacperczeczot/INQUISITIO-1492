# Sesje playtestowe

Notatki z rozgrywek papierowego prototypu. **Nie commituj fikcyjnych wyników** — tylko realne sesje.

## Naming

```
YYYY-MM-DD-skrot.md
```

Przykłady: `2026-08-12-3p-oficjum.md`, `2026-08-15-prog-8.md`

1. Skopiuj [`_TEMPLATE.md`](_TEMPLATE.md)
2. Uzupełnij po sesji
3. Jeśli zmieniłeś karty: zaktualizuj [`../heresy-calibration.md`](../heresy-calibration.md) i log w [`../balance-notes.md`](../balance-notes.md)

## Checklista przed sesją

- [ ] Setup wybrany z [`../setups.md`](../setups.md) (2–3p lub 4–5p)
- [ ] Próg oskarżenia ustalony (**7** lub **8**)
- [ ] Wydruk / szkic planszy ([`../../game/board/locations.md`](../../game/board/locations.md))
- [ ] Planszetki z Torem Herezji ([`../../game/board/player-board.md`](../../game/board/player-board.md))
- [ ] Talie frakcji (10 kart) + Talia Czasu (8)
- [ ] Żetony: Herezja, złoto, Relikwie, Kontrola, Wskazówki, Stosy / Upadek
- [ ] Zasady: [`../../docs/rules/README.md`](../../docs/rules/README.md)
