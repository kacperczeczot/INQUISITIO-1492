# Sesje playtestowe

Notatki z rozgrywek papierowego prototypu. **Nie commituj fikcyjnych wyników** — tylko realne sesje.

## Naming

```
YYYY-MM-DD-skrot.md
```

Przykłady: `2026-08-12-3p-oficjum.md`, `2026-08-15-warstwa-b.md`

1. Skopiuj [`_TEMPLATE.md`](_TEMPLATE.md)
2. Uzupełnij po sesji (pola dramatyczne: Herezja, Autodafé, Werdykt, Haki, Podwójni)
3. Log hipotez w [`../balance-notes.md`](../balance-notes.md)

## Checklista przed sesją

- [ ] Setup **3 / 4 / 5p** z [`../setups.md`](../setups.md)
- [ ] Warstwa A/B/C ustalona
- [ ] Próg oskarżenia (**7** lub **8** — eksperyment dramatyczny)
- [ ] Plansza + Inkwizytor ([`../../game/board/locations.md`](../../game/board/locations.md))
- [ ] Planszetki Tor Herezji ([`../../game/board/player-board.md`](../../game/board/player-board.md))
- [ ] Karty wg warstwy + (C) Talia Czasu
- [ ] Komponenty: Hak, Podwójny, Relikwie, złoto, Stosy/Fragmenty
- [ ] Zasady: [`../../docs/rules/README.md`](../../docs/rules/README.md)
