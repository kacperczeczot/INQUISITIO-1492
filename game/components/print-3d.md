# Lista elementów do druku 3D — prototyp playtest

Komplet pod pierwszą testową grę (do **5 graczy**).  
Karty, plansza i planszetki = **druk papierowy** (nie tu).  
Źródło ilości: [`inventory.md`](inventory.md), zasady: [`../../docs/rules/README.md`](../../docs/rules/README.md).

---

## Priorytet 1 — obowiązkowe

### Agenci (figurki pionków)

**3 na frakcję** × **5 frakcji** = **15 szt.**

| # | Frakcja | Kolor (sugerowany) | Silueta / motyw |
| :---: | :--- | :--- | :--- |
| 1–3 | Święte Oficjum | czerwień / czerń | inkwizytor, familiariusz, kaptur + krzyż |
| 4–6 | Cienie Al-Andalus | zieleń / turkus | asasyn, brat w kapturze, sztylet |
| 7–9 | Korona & Borgiowie | złoto / fiolet | dworzanin, kapitan straży, herb |
| 10–12 | Kabała z Toledo | błękit / srebro | uczony, alchemik, księga / gwiazda |
| 13–15 | Gildia Cieni | szarość / czerń matowa | złodziej, szantażysta, maska |

Wymagania: wysokość ~25–35 mm (czytelne na planszy A3), baza okrągła z miejscem na kolor frakcji, 5 wyraźnie różnych siluet.

## Priorytet 2 — żetony (zalecane w 3D)

| Element | Ilość | Kształt / uwagi |
| :--- | ---: | :--- |
| Relikwia | **8** | kafelek / medalion; 1–2 warianty wyglądu OK |
| Wskazówka Kodeksu | **6** | mały heks / fragment pergaminu |
| Złoto | **40** | moneta / dysk; można 2 rozmiary (1 i 5) |
| Kontrola / Wpływ | **30** | kwadrat / tarcza; opcjonalnie 3 warianty lokacji (Trybunał, Pałac, Rynek) ×10 |
| Stos / Autodafé | **3** | płomień + stos / krzyż inkwizycji |
| Upadek frakcji (Gildia) | **2** | czarna pieczęć / zbita tarcza |

## Priorytet 3 — opcjonalne (nice to have)

| Element | Ilość | Po co |
| :--- | ---: | :--- |
| Zapasowi Agenci | **+5** (1 na frakcję) | inventory dopuszcza 3–4; zapas przy zgubieniu |
| Marker pierwszego gracza | **1** | zegar / pieczęć Toledo |
| Marker Szlaku Morskiego | **1** | statek / kotwica (Flota Kolumba) |
| Stojak / uchwyt na Relikwię w Lochach | **1** | wyróżnienie lokacji |

---

## Nie drukować w 3D (papier)

- Plansza 5 lokacji (A3)
- Planszetki gracza ×5
- Karty frakcji (10 × 5) + Talia Czasu (8)
- Karty pomocy / cele zwycięstwa
