# Lista elementów do druku 3D — prototyp playtest

Komplet pod pierwszą testową grę (**3–5 graczy**).  
Karty, plansza i planszetki = **druk papierowy** (nie tu).  
Źródło ilości: [`inventory.md`](inventory.md) · zasady: [`../../docs/rules/README.md`](../../docs/rules/README.md).

---

## Priorytet 1 — obowiązkowe

### Wielki Inkwizytor (NPC)

| Element | Ilość | Uwagi |
| :--- | ---: | :--- |
| Figurka Wielkiego Inkwizytora | **1** | Wyższa niż Agent (~40–50 mm); baza z miejscem na żeton stanu **Patrol / Autodafé** |

Silueta: mitra / krzyż / płaszcz. Czytelna z daleka na planszy A3.

### Agenci (figurki pionków)

**3 na frakcję** × **5 frakcji** = **15 szt.**

| # | Frakcja | Kolor (sugerowany) | Silueta / motyw |
| :---: | :--- | :--- | :--- |
| 1–3 | Święte Oficjum | czerwień / czerń | inkwizytor, familiariusz, kaptur + krzyż |
| 4–6 | Cienie Al-Andalus | zieleń / turkus | asasyn, brat w kapturze, sztylet |
| 7–9 | Korona & Borgiowie | złoto / fiolet | dworzanin, kapitan straży, herb |
| 10–12 | Kabała z Toledo | błękit / srebro | uczony, alchemik, księga / gwiazda |
| 13–15 | Gildia Cieni | szarość / czerń matowa | złodziej, szantażysta, maska |

Wymagania: wysokość ~25–35 mm, baza okrągła z kolorem frakcji, **5 wyraźnie różnych siluet**.

### Nakładki Podwójny Agent

| Element | Ilość | Uwagi |
| :--- | ---: | :--- |
| Pierścień / klips na bazę Agenta | **8** | Oznacza Podwójnego; zdejmowalny; nie zasłania koloru frakcji |

### Znaczniki Herezji (płomienie)

| Element | Ilość |
| :--- | ---: |
| Marker płomienia / mały pionek na Tor Herezji | **5** (1 na gracza) |

| Dekret (Korona) | **4** | pieczęć / pergamin (postęp signature) |
| Stan Inkwizytora | **2** | małe dyski: Patrol / Autodafé (jeśli nie na bazie figurki) |

## Nie drukować w 3D (papier / PnP)

- Plansza 5 lokacji (A3 lub 2×A4)
- Planszetki gracza ×5 (Tor Herezji)
- Karty frakcji (10 × 5) + Talia Czasu (8+)
- Teach sheet / cele zwycięstwa
