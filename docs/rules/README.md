# Zasady gry — szkic

> Pełny rulebook powstanie po Fazie 1 (prototyp talii). Poniżej szkielet z GDD.

## Setup (roboczy)

1. Rozłóż planszę 5 lokacji.
2. Każdy gracz wybiera frakcję (asymm.), bierze talię, Agentów, planszetkę z Torem Herezji (start: 0).
3. Wymieszaj Talię Czasu; odłóż stos zakryty.
4. Rozmieść Relikwie / żetony startowe według scenariusza prototypu.
5. Dobierz rękę startową (liczba TBD — proponowane 5).

## Runda = 4 fazy

### I. Wydarzenie Historyczne (Talia Czasu)

Odkryj kartę; zastosuj globalny modyfikator.

### II. Planowanie Intryg

Naprzemiennie: zagraj **zakrytą** kartę Akcji pod lokacją + (opcjonalnie) umieść Agenta.

### III. Odkrycie i Konfrontacja

Od lokacji 1 → 5: odkryj karty, rozpatrz efekty, starcia Agentów, Herezję, transport Relikwii.

### IV. Sąd Inkwizycyjny & Czyszczenie

Sprawdź Tory Herezji, rozpatrz oskarżenia/procesy w Lochach, zbierz zasoby, dobierz do limitu ręki, następna Era.

## Zwycięstwo

Gracz spełnia **warunek Intrygi swojej frakcji** (patrz `game/factions/`).  
Opcjonalnie: limit Er — zwycięzca wg punktów Wpływu / postępu Intrygi (TBD w playtestingu).
